# 🌳🌲 Decision Tree vs Random Forest — Fruit Classifier

A simple beginner-level ML project comparing **Decision Tree** and **Random Forest**
classifiers on a tiny fruit dataset (Apple 🍎 vs Orange 🍊) using Weight and Size as features.

## 📌 What it does
- Trains a **Decision Tree Classifier** (single tree)
- Trains a **Random Forest Classifier** (ensemble of 10 trees)
- Compares their accuracy on test data
- Predicts the class of a new, unseen fruit

## 🧠 Concept
- **Decision Tree** → one model making step-by-step splitting decisions
- **Random Forest** → many decision trees trained on random subsets, combined by majority vote (usually more accurate & stable)

## 🛠️ Tech Used
- Python
- scikit-learn

## 🚀 How to Run
```bash
pip install -r requirements.txt
python fruit_classifier.py
```
